# Planner 2027 · Meu Planner para uma Feliz Vida

App pessoal (PWA) com retrospectiva de 2026, Sonhar e Projetar, planejamento financeiro, quadro dos sonhos, carta ao futuro, 12 meses com planner semanal, revisões trimestrais e listas.

- Funciona offline e pode ser instalado no celular, tablet e computador.
- Sincroniza entre aparelhos via Supabase (login com e-mail e senha).
- Configuração em `config.js` (Project URL + chave anon/publishable do Supabase).

Hospedado no GitHub Pages: Settings → Pages → Deploy from a branch → `main` / root.
